# NvChad IDE's custom

## clone NvChad to ~/.config/nvim

```shell
git clone https://github.com/NvChad/NvChad -b v2.0 ~/.config/nvim
```

## clone this custom to ~/.config/nvim/lua/custom/

```shell
git clone https://github.com/user00000001/public_repos -b nvchad-custom-v2.0 ~/.config/nvim/lua/custom
```

## launch neovim

```shell
nvim
```
